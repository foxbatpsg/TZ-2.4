# Таблица canonical: норма → первичный источник

Зафиксированное соответствие «норма → первичный источник». Использовать при работе с конкретной
нормой: формулировка берётся из `canonical`, все прочие вхождения считаются `mentions` и
проверяются на расхождение.

## Как читать эту таблицу

Норма с большим числом вхождений (`A-03` — 9, `A-11`/`A-16` — по 5) при правке требует проверки
**всех** мест: формулировки могут расходиться по акцентам, и выбор «удобного» определения создаёт
вторую «истину». При обнаружении расхождения — внести в поле `conflicts` и в §9 `INDEX.md`.

Обновлять эту таблицу при: добавлении нормы, изменении `canonical`, закрытии дефекта.
